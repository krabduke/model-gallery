      How they are built

      One file holds every dimension

      Each project has a spec.py carrying every measurement, mass and material. No geometry module holds a literal dimension: if a number describes the machine, it lives in one place.

      Every project checks itself

      make verify measures what was built and asserts it against the specification: envelope, clearances, joints, kinematics, stability, performance. It has caught real design errors.

      Drawn to scale

      make drawings writes an A1 package: a general arrangement and a sheet for every assembly, third-angle projection, dimensioned, with a numbered parts list.

      Checked by an outside solver

      The aerodynamics went through OpenFOAM on the geometry exactly as built. It found the car's fans could not breathe and its balance was wrong, and both were fixed in the models.
