How these are built

One file holds every dimension

Each project has a spec.py carrying every measurement, mass and material. No geometry module contains a literal dimension — if a number describes the machine, it lives in one place and everything else derives from it.

The geometry is testable without Blender

Everything up to the part builders is pure Python with no bpy import, producing plain vertex and face lists. Blender is the last stage, not the environment the work happens in.

Every project checks itself

make verify measures what was actually built and asserts it against the specification — envelope, balance, kinematics, stability, performance. Several real design errors were caught this way and are documented in each repository.
