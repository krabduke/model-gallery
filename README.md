# Parametric machines

A landing page for six machines, each generated procedurally in Blender from a
single specification file: engines, and the vehicles built around them.

**Live: https://krabduke.github.io/model-gallery/**

| | Project | |
|---|---|---|
| Engine | [Aether AX-1 adaptive-cycle turbofan](https://github.com/krabduke/aether-ax1) | 134.9 kN reheat, 120 checks |
| Vehicle | [Nyx agile fighter](https://github.com/krabduke/nyx-jet) | 35 °/s instantaneous turn, 30 checks |
| Engine | [RX-8V V8 hybrid](https://github.com/krabduke/car-engine-v8-hybrid) | 2.0 L, 1,254 hp, 40 checks |
| Vehicle | [VX-1 Vortex fan car](https://github.com/krabduke/aero-hypercar) | 700 kg, beats F1, 45 checks |
| Engine, v1 | [F110-GE-129 turbofan](https://github.com/krabduke/f110-turbofan) | 2,044 airfoils, 50 checks |
| Vehicle, v1 | [RC Jet](https://github.com/krabduke/rc-jet) | 558 g, 34 checks |

Each vehicle imports its engine's generators and installs them rather than
re-modelling the engine. The v1 aviation pair is kept as it was, at tag `v1`.
