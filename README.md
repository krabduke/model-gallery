# Parametric machines

A landing page for four machines, each generated procedurally in Blender from a
single specification file. Two engines, and the vehicles built around them.

**Live: https://krabduke.github.io/model-gallery/**

| | Project | |
|---|---|---|
| Engine | [F110-GE-129 turbofan](https://github.com/krabduke/f110-turbofan) | 99 parts, 2,044 airfoils, 46 checks |
| Vehicle | [RC Jet](https://github.com/krabduke/rc-jet) | 440 × 300 mm, 330 g, 23 checks |
| Engine | [RX-8V V8 hybrid](https://github.com/krabduke/car-engine-v8-hybrid) | 2.0 L, 1,254 hp, 21 checks |
| Vehicle | [VX-1 Vortex fan car](https://github.com/krabduke/aero-hypercar) | 700 kg, beats F1, 31 checks |

Each vehicle imports its engine's generators and installs them at scale rather
than re-modelling the engine.
